## 零、先看这条：游戏名有风险 ⚠️

当前 `CONFIG.meta.name = '雷霆战机'`。

- **运营规范 2.5**：「不能使用广义归纳类、普遍且不具有识别性的词汇来命名」。
  "雷霆战机" 属于典型的通用描述词，极大概率**已存在同名/近名小程序**，会被判重复或混淆而驳回。
- **运营规范 2.1.4 / 2.8.1**：不能侵权他人游戏或 IP。**"雷电" 是 Seibu Kaihatsu 的商业 IP**，
  名称、简介、美术、弹幕设计都不能蹭。本项目是弹幕射击这一**玩法类型**的原创实现，
  美术全部代码绘制、无素材复用，只要名字和文案不碰 IP 就没有侵权问题。

**建议**：改成 "品牌词 + 玩法描述" 的形式，例如「星陨雷霆」「雷霆弹幕：深空突袭」……
名字定下来后改 `src/config.js` 的 `CONFIG.meta.name` / `enName` 一处即可，
启动页、菜单、分享文案、分享战绩图全部跟着变。

### 真机体验硬伤：手机没有 P / R / Q 键

之前暂停、重开、退出、换弹全部绑在键盘上 —— 真机上**一个都按不了**。已补：

- HUD 右上角常驻**暂停按钮**（`uiLayout().pause`，避开安全区）
- 暂停面板：继续 / 重新开始 / 音效开关 / **退出游戏**（`wx.exitMiniProgram`，仅小游戏显示）
- 新增通用命中系统 `UI.hits`：面板绘制时注册可点区，点击时统一派发 action
  （`start / help / info / back / menu / pause / resume / restart / sound / exit / share`）

## 三、上架流程（代码之外的硬门槛）

1. **主体**：必须是**企业/个体工商户**主体。个人主体拿不到游戏版号，无法上线带商业化能力的小游戏。
2. **游戏类目**：注册时选「游戏」类目 —— **一经选择不可变更**（特别规范 1.1）。
   二级类目按实际玩法选（本项目属「射击」类），不能靠挂其他类目规避管理（1.5）。
3. **软件著作权**：需有该游戏的《计算机软件著作权登记证书》（1.2、1.4）。
4. **游戏版号**：国家新闻出版署审批的**网络游戏出版物号（ISBN）+ 批准文号**。
   拿到后填进 `CONFIG.meta.copyright`，会显示在启动页与「版号信息」页（2.6.1）。
5. **小程序备案**：按工信部要求在微信后台完成备案。
6. **《用户隐私保护指引》**：后台必须配置并声明。本项目只在本机存最高分/音效开关/引导标记，
   **不采集、不上传任何用户信息**，声明时如实勾选"不收集"即可。若后续加排行榜会用到
   `wx.setUserCloudStorage`，届时需在指引里补充并走 `wx.requirePrivacyAuthorize`。
7. **提审材料**：名称、图标、简介、截图、玩法演示视频；必要时提供软著与版号扫描件。

### 名称 / 图标 / 简介 写法（规范 2.1 ~ 2.5）

- 名称、logo、简介**三者要有明确关联**，别各说各话
- 不得含政治敏感、色情、暴力恐怖、违法内容
- **不得含商业化用语**（"免费""巨便宜""清仓"）、"国家级""最高级"等广告法禁用语、热门词堆砌
- 名称与内容必须具备关联性：不能叫"三国群英"做消除
- 名称/简介**不可包含金钱、实物奖励相关的诱导描述**（2.1.5）

## 四、还没做但建议排期的

1. **好友排行榜**（指南 3.3 称之为"必不可少"）
   需要：开放数据域子项目（独立 `game.json` 标注 `openDataContext`）+ 主域 `wx.setUserCloudStorage`
   上报分数 + `wx.getFriendCloudStorage` 取数。改动不小，建议单开一轮。
2. **客服 / 游戏圈**：后台配置即可，代码零改动。指南 4.4 明确建议配。
3. **复活 + 激励视频**：复活后要给足准备时间与预判提醒（2.5）。
4. **成就 / 收集目标**：图鉴系统（4.2）。
5. **低端机降级**：按帧率动态降 dpr 或减粒子。

## 五、本项目的天然合规项（不用改）

- 无赌博玩法、无随机抽卡、无虚拟货币（2.5.1 ~ 2.5.3）
- 无强制对战（2.5.4）
- 无红包提现玩法（2.5.5）
- 无血腥恐怖场景、无色情内容（2.4）
- 音乐音效为代码合成，**不存在版权问题**（2.3.1）
- 无用户自定义头像/昵称、无世界聊天（不会有内容安全风险，2.7.1）
- 无互推跳转、无误触跳转（2.10）
- 无诱导下载 APP（5.20）
